# 캐릭터 삭제 시 등록된 반려동물 정보 유지

## 문제와 원인

등록된 반려동물로 캐릭터를 만든 뒤 캐릭터를 삭제하면 원래 반려동물 정보까지 삭제되었습니다.
`CharacterService.deleteCharacter()`가 캐릭터 삭제 후 `userPetRepository.delete(pet)`도 호출한 것이 원인입니다.

## 변경 내용

- `DELETE /api/characters/{characterId}`에서 반려동물 삭제 호출을 제거했습니다.
- 캐릭터와 연결된 성장 기록만 삭제하며, 등록된 반려동물 정보는 유지합니다.
- 기존 사용자 소유권 확인 로직과 API 경로·응답 형식은 그대로입니다.
- 프런트엔드 삭제 확인 창에도 반려동물 정보가 유지됨을 표시했습니다.

## 백엔드 반영 사항

변경된 백엔드를 빌드·배포하고 재시작해야 반영됩니다. 이번 수정에 DB 스키마 변경은 없습니다.
이미 삭제된 반려동물 데이터가 이 수정으로 복원되지는 않습니다.

## 검토 및 직접 확인할 흐름

사용자 요청에 따라 변경 파일의 코드만 검토했으며, 빌드나 동작 테스트는 실행하지 않았습니다.
동작 확인은 사용자가 직접 진행합니다.

1. 기존에 등록한 반려동물로 캐릭터를 생성합니다.
2. 캐릭터 키우기 목록에서 해당 캐릭터를 삭제합니다.
3. 캐릭터는 목록에서 사라지고, 등록된 반려동물 정보는 남아 있는지 확인합니다.
4. 같은 반려동물로 캐릭터를 다시 생성할 수 있는지 확인합니다.
